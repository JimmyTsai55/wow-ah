## 各 agent 以「目前資料」能做什麼

### 1. 配方利潤分析師（spreads）— 可用，但範圍很窄
只有 **1 個配方**材料與成品都有價，能實際算利潤（數字已用 `spreads` 指令驗證）：

**Flask of Alchemical Chaos**（此快照數字）
- 材料成本：Mycobloom×10 (159g 90s) + Luredrop×5 (65g 45s) + Aqirite×2 (20g) = **245g 35s**
- 成品售價：137g，扣 5% 拍賣場手續費 (6g 85s) → 淨得 130g 15s
- **利潤：約 −115g 20s（虧損，利潤率 ≈ −47.0%）**
- ✅ 可預測結論：**現在製造這支藥水販售會虧本**——材料比成品還貴（而且材料漲價後虧更多：前一天還只虧 ~49g）。

其餘 12 個配方（Algari 藥水系列、各式食物與茶）→ agent 會回報「成品無價、無法評估」。

> ⚠️ **重要陷阱（實測過）**：`spreads` / `get_spreads` 的 `min_margin` 預設是 `0`，會**過濾掉虧損配方**。
> 因為 Flask 是虧損，預設參數下它會被藏起來——`wow-ah spreads` 顯示「No recipes with sufficient margin found」，agent 用預設呼叫 `get_spreads` 也拿到空清單。
>
> 實測 `gpt-4o-mini`：**即使問題明講「包含虧損」，它也不會主動傳負的 `min_margin`**，所以 agent 只會說「配方存在但無利潤資料」，**算不出 −115g 的虧損數字**。這是小模型的能力限制（較強的模型較可能主動帶參數）。
>
> ✅ 要可靠看到這個唯一有數據的配方的真實損益，**用 CLI 直接指定負門檻**（繞過 agent）：
> ```bash
> wow-ah spreads --min-margin=-100      # 顯示含虧損的配方
> ```

### 2. 價格趨勢分析師（trends）— 目前無法用
- 需要 **≥24 小時**歷史（`MIN_DATA_POINTS=24`），目前只有 0–1 小時。
- 現在問買賣時機，agent 會誠實回報「資料不足、無 BUY/SELL/HOLD 訊號」。
- ⏳ 何時可用：持續每小時 `fetch`，累積約 24 次後開始有訊號。

- 目前每個 item 只有 1 筆資料，agent 會正確指出「樣本太少、不可靠、勿據此決策」。

## 現在就能實驗的問題（會得到有根據的回答）

```bash
# 先設定模型（或寫進 .env）
export OPENAI_DEFAULT_MODEL=gpt-4o-mini

# 1. 問配方損益（實測：gpt-4o-mini 會提到 Flask 存在，但不會算出虧損數字，因它沒傳負 min_margin）
wow-ah ask "把所有能算利潤的配方都列出來，包含虧損的，告訴我 Flask of Alchemical Chaos 划不划算？"

# 2. 只問賺錢的配方 — 預期：回「目前沒有有利可圖的配方」(因 Flask 虧損被預設門檻濾掉)
wow-ah ask "現在有哪個配方做來賣會賺？"

# 1b. 要真實虧損數字 → 用 CLI（agent 算不出，這是可靠來源）
wow-ah spreads --min-margin=-100      # → Flask -115g 20s, -47.0%

# 3. 材料行情 — 預期：列出 6 個有價 item
wow-ah ask "現在這些煉金材料的價格各是多少？"

# 4. 趨勢（測資料不足的誠實回報）— 預期：回報歷史不足、無訊號
wow-ah ask "現在有沒有適合買進的物品？"

# 5. 完整建議報告
wow-ah advise

# 直接看數字（繞過 agent，CLI 驗證）— 顯示含虧損
wow-ah spreads --min-margin=-100
```

> 對照組 1 vs 2 正好示範了 `min_margin` 預設門檻的效果：問「含虧損」會看到 Flask，只問「會賺的」則回空。

## 「預測範圍」一覽：現在能 / 需要更多資料

| 能力 | 現在可做 | 需要什麼才解鎖 |
|---|---|---|
| 單一配方利潤（Flask） | ✅ 可算（虧損） | — |
| 多配方利潤比較 | ⚠️ 僅 1 個有數據 | fetch 到成品也有價（多數成品非商品 AH，可能需要擴充資料來源） |
| 材料價格現況 | ✅ 6 個材料 | — |
| 買低賣高時機（趨勢） | ❌ | 累積 ≥24 小時、每小時 fetch |
| 跨時段波動/百分位 | ❌ | 同上 |
| 風險審查（信心評估） | ✅ 會說「低信心」 | 累積更多筆數後才會有意義 |

## 如何擴大可預測範圍

1. **累積歷史**：每小時跑 `wow-ah fetch`（可用排程），約 24 小時後趨勢分析才有訊號。
2. **補成品價格**：多數配方成品目前無商品 AH 價，是 spreads 算不出的主因；要更廣的利潤分析需擴充成品的價格來源。
3. **資料越多，risk 審查越有意義**：單點資料只能給「低信心」，多筆後才能判斷異常。
